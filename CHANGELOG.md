- Whole-Pi Docker Sandboxes launch through Pi flags and `pi-dsbx`.
- Clone-mode default, no-shared-skills enforcement, strict configuration, Kit v2 generation/validation, credential registry, and network profiles.

- Persistent sandbox metadata, session backup primitives, safe binary Git patch export/apply, status, doctor, destroy, and pinned image builder.
- Unit, injection, sanitizer, Git, signal, real microVM security, private-Docker, and extension re-exec tests.
